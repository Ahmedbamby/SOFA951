# Go Clean — صفحة هبوط لخدمات التنظيف

صفحة عربية سريعة ومتجاوبة لخدمات تنظيف الكنب والمجالس والسجاد، جاهزة للرفع على GitHub Pages أو أي استضافة ثابتة.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل المجلد عبر أي خادم محلي بسيط.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من إعدادات المستودع افتح **Pages**.
3. اختر النشر من فرع `main` والمجلد `/root`.
